# 主结果与主回归的正文逻辑

## 使用场景

用于决定主回归表、核心事实图或主结果段如何进入中文正文。表格版式交给 `econ-table-figure-design`；本文件只判断论证位置和解释顺序。

本文件中的 `表图定位`、`该结果如何支撑机制或后续检验` 等检查语言只用于作者备忘、审稿报告、任务 README 或修改清单，不得原样进入论文正文。写入正文时，应改成具体的估计结果、经济含义、识别可信度、机制连接或下一步检验对象。

涉及系数大小、回归结果量级、交互项、边际效应、概率模型、对数转换、均值/标准差/分位差比较时，先读取 `econ-writing-workflow/references/regression-results/01_economic_magnitude_interpretation.md`，再写中文正文。

## 主结果准入

正文主结果必须满足：

- 直接回答研究问题，而不是展示所有做过的规格。
- 估计设定与理论机制、识别设计一致。
- 样本、变量和固定效应的变化能够解释。
- 结果方向、量级和经济含义清楚。
- 不依赖单个偶然显著列支撑全文结论。

不满足这些条件的结果，优先放入附录、稳健性说明或规格审计文件。

## 解释顺序

主结果段默认按以下顺序写：

```text
表图定位 -> 核心系数方向和量级 -> 量级基准 -> 结果对象或阈值是什么 -> 经济含义 -> 识别可信度或关键控制 -> 与机制的连接 -> 必要时整合新的具体边界或下一步检验
```

这是论证顺序，不是要求每个主结果段都配一句免责声明。默认通过准确动词、claim type 和必要范围限定体现证据强度，并正面说明估计量、阈值、情景或模型对象是什么、度量什么、说明什么；这不是乐观包装。首次或唯一一句否定性 caveat 也必须绑定具体结论或数字，阻止现有措辞尚未排除的实质误读。若它只在否定句中引入新对象，就把这一点视为强烈的删除信号；若必要边界可以并入结果解释，就删除或整合。只有具体、实质的误读仍存在且正面说明无法排除时，才把与具体对象绑定的独立否定句作为最后手段保留。同一非因果、外推或期间限制在首次真正需要处已经说清后，后续表图不反复复述。只有方法、样本、时期、地域、外推对象或证据等级改变，或表注/图注必须脱离正文独立理解时，才重新写出对应限定。

上述“最后手段”不由 AI 自行授权。若精确否定命题未进入作者已确认并冻结的意图契约，先提交正面解释和拟保留对照供作者裁决，返回 `clarification_required`，不得直接把它放入主结果段。

写作时避免逐列复述。正文只解释读者理解论点所需的列：

- 哪一列是基准规格。
- 哪一列加入关键控制或固定效应。
- 哪一列用于说明样本或识别稳健性。
- 哪一列不应在正文中过度解释。

量级基准至少选择一个真正适合本文问题的口径：自然单位、政策变化幅度、百分点、百分比转换、均值、标准差、P75-P25、P90-P10、边际效应或交互项净效应。中文正文不要求每个结果同时报告均值、标准差和分位差；机械堆叠多个基准会削弱主结果段的论文感。

## 样本与规格审计

主表进入正文前应回答：

- 各列样本量为什么变化。
- 样本变化是否来自控制变量缺失、固定效应、单例剔除、变量口径或样本构造。
- 剩余样本是否仍代表目标识别总体。
- 规格变化是在增强可信度，还是只是追求显著性。

## 反面写法

- “列(1)-(6)均显著，因此结论稳健。”
- “加入控制变量后结果依然显著”，但没有说明控制了什么和为什么。
- 把每个系数逐一读出，却没有解释经济含义。
- 只说显著性，不给方向、量级或变量单位。
- 缺少描述统计时自行编造均值、标准差、分位点或政策变化幅度。
- 只解释交互项符号，不计算有意义取值或分组下的净效应/边际效应。
- 在没有具体误读链时，突然以“X不是Y”收尾，却不解释 X 本身的定义、量度对象和用途。
- 每张表后都写“本结果不具有因果含义”“不能外推”或“无法判断长期效果”，却没有新的样本、方法、时期或证据等级变化。

## 检查标准

主结果段完成后，读者应能知道：

1. 主结论是什么。
2. 量级意味着什么。
3. 为什么该规格可信。
4. 该结果如何支撑机制或后续检验。

上述第 4 项是作者检查问题，不是正文句式。正文中不要写“该结果支撑机制”，而要说明结果与哪条机制链条一致，或它为后续哪个机制/稳健性检验提供依据。
