# 中文期刊共同投稿体例规则

## 通用匿名审稿 Word 底盘

- 当目标期刊尚未完全锁定，或用户要求“中文顶刊通用格式”“先做审稿版 Word”时，先生成通用匿名审稿版，再叠加具体期刊的硬性要求。
- 通用版优先保证可读、匿名、编号稳定和图表清晰，不把某一刊的录用后排版当成所有中文顶刊的通用格式。
- 页面默认采用 A4，页边距约 25mm，插入页码。
- 正文中文字体默认用宋体小四或五号，英文和数字用 Times New Roman；行距默认 1.5 倍或固定 20--22 磅。若目标期刊已有硬性要求，以目标期刊为准。
- 标题层级默认采用中文经济学论文常见编号：`一、`、`（一）`、`1.`、`（1）`。不要在未锁刊阶段强行套用某一刊的标题字体、占行和缩进细则。
- 默认准备封面页和匿名正文首页两个层次。封面页放作者、单位、通信地址、邮箱、基金和致谢等身份信息；匿名正文首页只放标题、摘要、关键词以及目标期刊需要的英文标题、英文摘要、英文关键词和 JEL 分类号。
- 投稿前必须删除正文、附录、脚注、致谢、自引措辞、文件属性和路径中的身份线索。
- 中文摘要在未锁刊时默认控制在约 300 汉字符以内，关键词默认 3--5 个。若目标为《经济研究》，还需另备英文梗概 Summary 及中文对照；若目标为《经济学》（季刊），再按该刊 200 字中文摘要、100 词英文摘要和 3 个 JEL 分类号等硬性要求调整。
- 参考文献先保证文中引用与文后条目一一对应；排序、编号、脚注和英文信息格式在目标期刊确定后再做最后适配。
- 最终交付前必须核对导出的 Word 或 PDF 成品，不能只以转换脚本、LaTeX 编译或 markdown 源文件看似正确作为完成标准。

## 跨页表格

- 凡表格跨页，下一页必须标注“续表”或“续表 X”。
- 续表页必须复写完整表头，至少包括被解释变量、列号、组别标题和必要列名。
- 不要让续表页只出现系数或统计量；读者翻到下一页时应能独立理解列含义。

## 图形清晰度

- 论文图形优先使用 PDF、SVG、EMF 等矢量或无损格式嵌入 Word。
- 确需位图时，使用高分辨率 PNG 或 TIFF；不要用截图、低清 JPEG 或经过多次压缩的图片。
- 最终检查应看导出的 PDF 或 Word 页面，而不是只看制图软件窗口。

## 图中文字

- 中文期刊图题、坐标轴、图例和图注尽量使用中文。
- 只有无法自然中文化或已形成通用写法的统计缩写可保留英文，例如 CI、p 值、GDP、DID。
- 图形字体采用硬规则；只有用户明确指定其他字体，或目标期刊官网明确规定其他字体时，才按更高优先级要求覆盖。
- 图题、坐标轴标题、图例、图注和图内标注中的中文统一使用宋体；英文、拉丁字母、阿拉伯数字和坐标轴刻度数字统一使用 Times New Roman。
- 图内字号必须在最终 PDF 中清楚可读；不能靠放大屏幕才能辨认。

## 正文图形准入

- 正文图形必须直接支撑研究问题、识别设计、核心事实、主结果或核心机制。
- 背景事实图、平行趋势图、补充稳健性图、额外异质性图和说明性图优先放附录。
- 核心机制分析原则上属于正文主线，不能因为篇幅压力默认移入附录。

## 附录引用

- 正文引用附录时，应具体到附录号、附图或附表号。
- 避免只写“见附录”这种模糊指向。
- 如果正文因篇幅压缩事实背景或稳健性细节，应在正文或脚注中明确说明读者可在何处查看。

## 变量命名

- 出现在回归式、构造式、描述性统计表或数据字典中的变量，可以给英文符号。
- 正文叙述、表格行名和变量解释优先使用中文称呼。
- 不直接进入公式、构造式或表格的普通概念，不必强行配英文名。
